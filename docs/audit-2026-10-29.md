# Site-audit 2026-10-29 (v0.17.2)

Volledige crawl van **Gratis planten** (Laravel 12), leeg én gevuld, plus mobiele checks. Gebaseerd op staging inclusief 0.17.0 (organisaties).

> `AGENTS.md` stond niet in de repo; gewerkt volgens README / INSTALL / CONTRIBUTING en de taakomschrijving.

## Aanpak

1. SQLite lokaal, `migrate --seed` (alleen `DeelplekkenSeeder` = verplicht).
2. **Leeg:** geen demo-users/aanbod; steden + soorten + organisaties uit JSON; deelplekken uit seed.
3. **Gevuld:** `php artisan db:seed --class=DemoSeeder` (8 users met locatie, ~24 aanbod, 1 gesprek met berichten).
4. Crawl: alle publieke routes, 48 soortpagina’s, 42 stadpagina’s, organisatiepagina’s (`/voor-organisaties`, `/organisaties`, `/organisaties/{slug}`), account- en beheerroutes; href/src-check; externe HEAD/GET.
5. Playwright-screenshots 375×812 en 768×1024 van elke paginasoort (`storage/app/audit-screenshots/`, lokaal).
6. Regression: `tests/Feature/RouteAuditTest.php` (leeg + gevuld, status &lt; 500; plus `/organisaties/{slug}` onder `config:cache` + `route:cache` met `APP_DEBUG=false`).

## Externe links

Crawl markeerde enkele URLs; na browser-UA-check:

- **Werkend:** stekjesroute, zadenbibliotheek, voedselbosbouw, meerbomen, eetbaargoed, permacultuur, netwerk voedselbosbouw, voedsel uit het bos, e.d.
- **False positives:** diverse deelplek-bronnen (status 200, curl chunked-read warning) — niet dood.
- **Open:** `https://velt.nu/…` geeft vanuit deze omgeving **403** (hele `velt.nu` / `velt.be`). Geen duidelijk geverifieerd alternatief; link blijft staan, hier genoteerd.

## Mobiel (Playwright)

Alle gemeten paginasoorten (home, aanbod, stektips, deelplekken, steden, account, beheer) op 375 en 768:

- Geen horizontale overflow
- Geen gemeten knoppen &lt; 44px hoogte (nav-toggle / `.btn` / `.nav-cta`)
- Kaarten (`#kaart`, `#deelplekken-kaart`, `#stad-kaart`) ≥ 280×200 px, leesbaar
- Stektips-tabel in scroll-container

## Reproduceerbaar

```sh
composer install && cp .env.example .env && php artisan key:generate
touch database/database.sqlite   # DB_CONNECTION=sqlite
php artisan migrate --seed
npm ci && npm run build
php artisan serve

# Gevuld
php artisan db:seed --class=DemoSeeder

php scripts/audit-crawl.php http://127.0.0.1:8000
# optioneel: node scripts/audit-mobile.mjs  (playwright lokaal)
./vendor/bin/pest --filter=RouteAudit
```
